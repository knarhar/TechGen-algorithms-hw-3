# TechGen Homework N3: Algorithms

### Task 1 – Balanced Brackets

Implemented an algorithm that checks whether a string consisting of the brackets (), {}, and [] is correctly balanced. The solution uses a custom stack implemented with an array to track opening brackets and verify that each closing bracket matches the most recently opened one.

### Task 2 – Flood Fill

Implemented the Flood Fill algorithm that starts from a given cell (x, y) and replaces all connected cells having the same initial value with a new value v. Connectivity is defined by the four neighboring cells (up, down, left, right). The solution is provided in two versions:
- Recursive version using Depth-First Search (DFS).
- Iterative version using a custom stack implemented with an array.
